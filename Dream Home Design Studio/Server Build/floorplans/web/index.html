    Good to know

    • Plans save as you draw. Edit a plan on one device at a time, or the edits overwrite each other.
    • Every plan is a .sh3d file in Design Studio/Floor Plans on the Butterfly Drive, and opens in desktop Sweet Home 3D.
    • To rename or delete a plan, use the Butterfly Drive. Deleted plans then go to Deleted files.
    • In the desktops, your files are in the Design Studio folder.
